# Registration checklist (EnginePerf), read before every prereg

1. Read the LAST prereg that used the same harness; copy its flags; list every expected output file next to the
   switch that produces it.
2. Every bound is derived for THIS arm from what this arm actually does. Write the derivation next to the bound:
   what each end means, and what a value outside it would say about the system. A bound copied from another arm or
   another team's text is marked "COPIED" in the margin table until it has its own derivation.
   (Three misses in one week: arm D gap ceiling/floor taken from a prediction; d1's floor; d2's spot check copied
   from d1, where the first pose is the track's start, into an arm where it cannot be.)
3. A check tests the outcome, not a log line, a time, a flag or a path.
4. A missing file fails by name; it is never read as 0.
5. Tags are all-lowercase. The re-run policy (`<tag>_rr`) and the scorer's name list come from one source.
6. Scorer self-test on fixtures that are real run folders, including one mutant per check.
7. Guesses with a percentage and the named risks. Score once; write the score output to a file in that same run.
8. Display: own number (`:141`) with exists-refusal. Ask the Overseer before each box run.
